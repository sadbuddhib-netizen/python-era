## ▶️ Run the Code

1. Install [Python](https://www.python.org/downloads/) if it isn't installed.
2. Clone this repository:
   ```bash
   git clone https://github.com/sadbuddhib-netizen/python-era.git
   ```
3. Open the project folder:
   ```bash
   cd python-era
   ```
4. Run the practice file:
   ```bash
   python functions.py
   ```

Some exercises request input in the terminal, such as student marks.
