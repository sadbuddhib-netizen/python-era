# Data Structures and Algorithms (DSA)

This folder contains my DSA practice in Python, starting with basic list traversal and searching.

## Current practice

1. `linear_search.py` — search for a target value in a list. Time: O(n), space: O(1).
2. `count_occurrences.py` — count how many times a target appears in a list. Time: O(n), space: O(1).

## Suggested learning order

- [ ] Python problem-solving basics: functions, loops, conditions, return values
- [ ] Arrays and lists: traversal, sum, min/max, reverse, duplicates
- [ ] Linear search and counting
- [ ] Time and space complexity: O(1), O(n), O(log n), O(n²)
- [ ] Two pointers
- [ ] Sliding window
- [ ] Sorting basics: bubble, selection, insertion; then merge sort and quicksort concepts
- [ ] Binary search
- [ ] Hash maps and sets
- [ ] Strings and common string problems
- [ ] Stack and queue
- [ ] Linked lists
- [ ] Recursion and backtracking
- [ ] Trees and binary search trees
- [ ] Heaps and priority queues
- [ ] Graphs: BFS and DFS
- [ ] Greedy algorithms and dynamic programming

## Practice rules

- Try each problem yourself before checking a solution.
- Test normal cases, missing targets, duplicates, empty lists, and edge cases.
- Write a short explanation of the approach and its time complexity.
- Use clear variable names and keep one main problem per file.

Run a file from the repository root, for example:

```bash
python dsa/linear_search.py
python dsa/count_occurrences.py
```
